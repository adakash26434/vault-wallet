PRODUCT DOCUMENT

Personal Key Wallet (Digital Life Vault)

⸻

1. 📌 Product Overview

Product Name: Personal Key Wallet
Category: Digital Security + Personal Finance + Identity Vault

🎯 Vision:

User को सम्पूर्ण digital जीवनलाई एउटै सुरक्षित स्थानमा राख्ने — जहाँ password, documents, OTP, र personal financial tracking सबै सुरक्षित र व्यवस्थित हुन्छ।

⸻

2. ❗ Problem Statement

आजका users ले सामना गर्ने समस्या:

* Password हराउने / बिर्सिने
* Multiple accounts manage गर्न गाह्रो
* OTP सुरक्षित राख्न नसक्ने
* Important documents छरिएको (mobile, email, paper)
* Monthly income/expense track नगर्ने
* Financial clarity नहुनु
* Security risk (leak, hack, phishing)

👉 सबै कुरा अलग-अलग apps मा छ → confusion + insecurity

⸻

3. 💡 Proposed Solution

Personal Key Wallet एक unified digital vault हो जसले:

3.1 Security Vault

* Device access info

3.2 Document Vault

* Citizenship
* Passport

* Secure file storage

3.3 Personal Finance Tracker

* Monthly income tracking

* Savings monitoring
* Budget control
* Financial insights

5. 🏗️ System Architecture

Frontend:

* Flutter (Android, iOS, Desktop)

Backend:

* Node.js / NestJS OR Firebase

Database:

* PostgreSQL (structured data)
* Encrypted object storage (documents)

Security Layer:

* AES-256 encryption
* PBKDF2 / Argon2 hashing
* Zero-knowledge architecture

⸻

6. 🔐 Security Model

Core Principle:

“Even system owner cannot read user data”

Features:

* End-to-end encryption
* Local encryption before upload
* Master password-based key generation
* Device binding
* Optional recovery key (12–24 words)

⸻
